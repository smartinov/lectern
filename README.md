# lectern

Personalized mini-courses, generated by an LLM agent, delivered to a Kindle.

Give it a topic and a target level. It researches the topic, writes N lessons of
about twenty minutes each, ends every lesson with a short self-check, and packages
the course as an EPUB 3 that Send to Kindle accepts as-is.

## Layout

```
skills/lectern/     agent skill: pipeline stages, lesson template, quiz rules
courses/<slug>/     one directory per course (spec, outline, sources, lessons, questions)
templates/          EPUB stylesheet and pandoc defaults
scripts/            build and validate helpers (pandoc, epubcheck)
learner/            private profile and history, ignored by git
build/              generated EPUBs, ignored by git
docs/decisions/     decision records
```

## Requirements

- pandoc 3.9 or newer (footnotes render as Kindle pop-ups from 3.9 on)
- epubcheck

## Build a course

```sh
scripts/build.sh courses/<slug>
```

The EPUB lands in `build/<slug>.epub`. Send it through Send to Kindle by email or
the web uploader.

## Course directory

| File | Purpose |
|---|---|
| `course.yaml` | topic, level, outcomes, lesson count, reading-time target, personalization notes |
| `outline.md` | ordered lessons with objectives and planned assessments |
| `sources.yaml` | verified references with dates and findings |
| `lessons/NN-slug.md` | one manuscript per lesson, quiz at the end |
| `questions.yaml` | stable question IDs, objective IDs, answers, rubrics |

Quiz answers live in an appendix at the end of the book. Each question links to
its answer and each answer links back to a continuation anchor, because hidden
or collapsible markup is unreliable on Kindle.
